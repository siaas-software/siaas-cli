# SIAAS CLI v0.2.0

Release candidate — publication pending acceptance.

## Added
- Read-only verification of official immutable Personal releases, including RC and exact-version selection.
- First-party Personal install, update and uninstall on Linux x64 only, with explicit consent and verified local operation receipts.
- Backward-compatible JSON schema v1, with optional personal.operation and sanitized failures.
- Private verified Node runtime provisioning; no automatic GUI or Ollama launch. Owned software removal preserves user data.

The CLI itself remains available for six OS/architecture targets. Personal lifecycle support is narrower; Windows, macOS and Linux ARM64 product mutations are not supported. Dry-run planning, rollback, start/stop/restart, generic third-party installations and purge are not included.

## Before publication
Public RC4 install/reinstall/uninstall acceptance and six-platform CLI tests are recorded in [JSON reporting evidence](../m2-json-reporting.md). Public RC4-to-RC5 update acceptance and exact release-candidate regression checks remain required. See [release readiness](v0.2.0-readiness.md). Existing unsigned distribution constraints remain; do not bypass OS policy.
