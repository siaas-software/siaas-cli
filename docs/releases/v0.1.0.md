# SIAAS CLI v0.1.0 — release candidate notes

Prepared for review; **not published and not approved for release**.

SIAAS CLI is a standalone command-line foundation, independent of SIAAS Personal.
End users do not need Node.js, npm, Electron, Docker, Ollama or Go.

Implemented commands: `siaas --help`, `siaas help`, `siaas --version`, and `--json`
output. Invalid usage returns 2; reserved product commands return 3.
**`siaas install personal` is not implemented in M1.** No product installation,
update, rollback, removal, process management or product discovery is included.

The Bash and PowerShell bootstraps install only the CLI, without an application
version. They validate release metadata, SHA-256 and size before replacement,
retain replaced executables, lock installations and use a user directory by
default. Downloads permit HTTPS on port 443 only, with at most five redirects
through GitHub's explicitly allowed release hosts. Publisher control of both
metadata and artifacts remains a trust assumption; checksums are not signatures.

All six native targets passed the original offline acceptance: Linux x64/ARM64,
Windows x64/ARM64 with Windows PowerShell 5.1, and macOS Intel/Apple Silicon.
The public-security follow-up adds default-path, NTFS ACL/reparse-point, Internet
origin metadata and genuine standard-user probes. See the current
[security review](https://github.com/siaas-software/siaas-cli/blob/feature/foundation-standalone-bootstrap/docs/public-release-security-review.md) for exact tested commits,
workflow outcomes and limitations; historical passes do not validate later code.

Remote candidates retain Windows Mark-of-the-Web or macOS quarantine before
replacement. No publisher Authenticode/Developer ID signature or notarization is
provided; Go's macOS ARM64 ad-hoc code signature is not publisher authentication.
Unsigned Internet scripts can be blocked by PowerShell policy and macOS assessment
can reject these candidates. No OS security bypass is recommended. Browser-based
SmartScreen/Finder acceptance, older OS support and real anonymous release
installation remain unverified. Publication requires an explicit distribution
risk/support decision and post-publication smoke tests.

Public installation instructions and trust/recovery guidance are in
[`docs/public-installation.md`](https://github.com/siaas-software/siaas-cli/blob/feature/foundation-standalone-bootstrap/docs/public-installation.md).
These instructions become usable for remote installation only after separately
authorized publication with the complete asset set. Until then, use reviewed
local builds and explicit local fixture options. Repository protection and
native validation gaps are recorded in the release-readiness report.
