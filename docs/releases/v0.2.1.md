# SIAAS CLI v0.2.1

Windows bootstrap usability patch; v0.2.0 CLI capabilities unchanged.

- Keep interactive PowerShell open when evaluating the installer; preserve numeric exit codes for file invocation.
- Default remote Windows installation configures user and current-process PATH without duplicate entries, preserving existing order and registry type.
- `-NoPath` opts out; custom or offline destinations require explicit `-AddToPath`.
- Preserve integrity, origin marking, locking and backup protections; no administrator privileges.

Personal mutations remain Linux x64 only. Unix installer behavior unchanged. Unsigned artifacts remain subject to normal OS policy.
